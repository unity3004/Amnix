# AMNIX Architecture

AMNIX is an AI-powered Security Operations Copilot designed to assist SOC analysts
with alert investigation, event correlation, threat intelligence enrichment,
MITRE ATT&CK mapping, and response recommendations.

## Core Components

- React Frontend
- FastAPI Backend
- PostgreSQL
- Redis
- Detection Engine
- Investigation Engine
- Threat Intelligence Layer
- MITRE ATT&CK Integration
- AI Copilot
- RAG Knowledge Layer
- OpenSearch
